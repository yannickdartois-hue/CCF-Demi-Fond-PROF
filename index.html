Fonctionnalités

⏱

Chronomètre terrain

Affichage large avec dixièmes de seconde. Glisser le temps sur l'élève pour saisie instantanée.

📊

Notes automatiques

Calcul instantané /10 et /20 — barèmes GT, Professionnel, CAP intégrés (BO 2021).

🏋

Mode Entraînement

500m + 2×1'30 avec notes indépendantes et zones de vitesse Z1→Z4.

📤

Export CSV & Excel

Exportez vos résultats en CSV ou XLSX sans aucune connexion internet.

💾

Sauvegarde auto

Sauvegarde automatique toutes les 30 secondes. Import/Export JSON pour reprendre une session.

📱

PWA installable

Installez l'icône sur l'écran d'accueil de votre iPad, iPhone ou tablette Android.

Installation en 3 étapes

Télécharger le fichier

Cliquez sur le bouton ci-dessus pour télécharger ccf_eps_v3.html sur votre appareil.

Ouvrir dans le navigateur

Ouvrez le fichier dans Safari (iPad/iPhone) ou Chrome (Android/PC). Aucune installation requise.

Optionnel — Ajouter à l'écran d'accueil

Sur iPad : bouton Partager → « Sur l'écran d'accueil ». Sur Android : menu ⋮ → « Ajouter à l'écran d'accueil ».
